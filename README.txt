# Getting and Cleaning Data Project

This repository contains my submission for the Getting and Cleaning Data Course Project on Coursera.

## Files

- `run_analysis.R`: Main script that performs the data cleaning and produces the tidy data set.
- `CodeBook.md`: Describes the variables in the final tidy data set.
- `README.md`: This file, which explains the process.

## How to run

1. Download and unzip the Samsung dataset into your R working directory.
2. Make sure the data folder is named `UCI HAR Dataset`.
3. Run `run_analysis.R` in R. It will generate `secTidySet.txt` as the tidy data output.
